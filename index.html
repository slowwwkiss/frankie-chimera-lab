    How it works

    Frankie is a Frankenstein: a chimera stitched from eight free public APIs — Advice Slip (brain), CoinGecko (heart), JokeAPI (funny bone), Dog CEO (eyes), Cat Facts (whiskers), wttr.in (weather skin), OpenLibrary (memory) and Bored API (hands). Each body part shows live data with its source and fetch time. If one API dies, that part fizzles and the rest of the creature lives on. Share a creature with a link — the part selection travels in the URL hash, and the data is fetched fresh on arrival.

    Built with Kiro for Kiroween 2026. Static HTML + JS, no backend, no keys.
